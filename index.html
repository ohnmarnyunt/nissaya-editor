Install လုပ်နည်း

Windows

  1. Nissaya Editor Setup.exe ကို နှစ်ချက်နှိပ်ပါ။
  2. “Windows protected your PC” ပေါ်လာပါက More info → Run anyway ကို နှိပ်ပါ။
  3. Next → Install → Finish ကို နှိပ်ပါ။ Desktop ပေါ်တွင် Nissaya Editor ပေါ်လာပါမည်။

Mac

  1. .dmg ဖိုင်ကို ဖွင့်ပြီး Nissaya Editor ကို Applications ထဲသို့ ဆွဲထည့်ပါ။
  2. Applications ထဲမှ Nissaya Editor ကို ဖွင့်ပါ။ “cannot be opened / could not verify” ဟု ပေါ်လာပါက Done ကို နှိပ်ပါ။
  3. System Settings → Privacy & Security ကို ဖွင့်ပြီး အောက်သို့ ဆင်းပါ။ “Nissaya Editor was blocked” ဘေးရှိ Open Anyway ကို နှိပ်ပြီး Mac password ရိုက်ထည့်ပါ။
  4. Keychain password မေးသော box ပေါ်လာပါက Mac password ရိုက်ပြီး Always Allow ကို နှိပ်ပါ။

ပထမဆုံး အသုံးပြုခြင်း

  1. App ကို ဖွင့်ပြီး Home စာမျက်နှာရှိ Google ဖြင့် ဝင်ရန် ကို နှိပ်ပါ။ Browser တွင် မိမိ Google account ကို ရွေးပြီး Allow ကို နှိပ်ပါ။ (ကွန်ပျူတာ တစ်လုံးလျှင် တစ်ကြိမ်သာ)
  2. စာအုပ်သစ် ဖန်တီးပြီး ဓာတ်ပုံ သို့မဟုတ် PDF ကို တင်ပါ။ PDF ဆိုလျှင် တစ်ကြိမ်လျှင် စာမျက်နှာ ၁၅ မျက်နှာ (အများဆုံး ၃၀) ရွေးနိုင်ပါသည်။
  3. နောက်တစ်ဆင့် - စာဖတ်ရန် ကို နှိပ်ပါ။ ပြီးလျှင် ဝါရောင် အတွဲများကို စစ်ပြီး စာမျက်နှာတိုင်းကို Checked လုပ်ပါ။
  4. Word, PDF သို့မဟုတ် Text ကို ဒေါင်းပါ။
စာအုပ်များ သိမ်းသည့်နေရာ - မိမိ ကွန်ပျူတာရှိ Documents/Nissaya Editor folder ထဲတွင်သာ ရှိပါသည်။ Cloud သို့ မပို့ပါ။ ဤ folder ကို USB သို့မဟုတ် Drive ထဲ မကြာခဏ ကူးထားပါ။
Internet - စာမျက်နှာ ဖတ်သည့်အဆင့် (OCR) တွင်သာ လိုပါသည်။ ပြင်ခြင်း၊ စစ်ခြင်း၊ ဒေါင်းခြင်းတို့ကို internet မရှိဘဲ လုပ်နိုင်ပါသည်။

Nissaya Editor

A desktop app that reads photos or PDFs of Pāli–Myanmar nissaya books, splits the text into Pāli–Myanmar pairs, lets you check them, and saves the result as Word, PDF or text.

How to install

Windows

  1. Double-click Nissaya Editor Setup.exe.
  2. If “Windows protected your PC” appears, click More info → Run anyway.
  3. Click Next → Install → Finish. Nissaya Editor appears on the desktop.

Mac

  1. Open the .dmg file and drag Nissaya Editor into Applications.
  2. Open Nissaya Editor from Applications. If it says it “cannot be opened” or “could not verify”, click Done.
  3. Open System Settings → Privacy & Security and scroll down. Next to “Nissaya Editor was blocked”, click Open Anyway and type your Mac password.
  4. If a Keychain box asks for a password, type your Mac password and click Always Allow.

First use

  1. Open the app and click Sign in with Google on the Home page. In the browser, choose your Google account and click Allow. (Once per computer.)
  2. Make a New book and add photos or a PDF. For a PDF you choose 15 pages at a time (at most 30).
  3. Click Next: Read the pages. Then check the yellow pairs and mark every page Checked.
  4. Download Word, PDF or Text.
Where your books are kept: only on your own computer, in the Documents/Nissaya Editor folder. Nothing is sent to the cloud. Copy this folder to a USB stick or Drive from time to time as a backup.
Internet: needed only while pages are being read (OCR). Editing, checking and downloading work offline.

Privacy

The app uses Google Drive only to read the pages. See the privacy policy for details.

Open-source components

  • Lexo (AGPL-3.0) – reads pages with Google Docs OCR. Included unchanged, as a separate program inside the app.
  • PyMuPDF (AGPL-3.0) – part of Lexo.
  • Noto Sans Myanmar (SIL Open Font License 1.1)
  • Pāli spelling check: Chaṭṭha Saṅgāyana Tipiṭaka text by the Vipassana Research Institute (VRI), used for non-commercial purposes.
